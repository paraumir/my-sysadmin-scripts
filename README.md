\# Мониторинг системных ресурсов



\## Описание



Этот проект содержит Bash-скрипт для мониторинга основных системных ресурсов Linux.



Скрипт собирает следующие данные:



\- Текущие дату и время

\- Время работы системы и среднюю нагрузку

\- Использование оперативной памяти (RAM) и раздела подкачки (swap)

\- Использование дискового пространства



Результаты отображаются в терминале и добавляются в файл `monitor.log`.



\## Требования



\- Linux или Ubuntu

\- Bash

\- Стандартные утилиты Linux: `date`, `uptime`, `free`, `df`, `sleep` и `tee`



\## Использование



Сделайте скрипт исполняемым:



```bash

chmod +x script.sh

```



Запустите скрипт с настройками по умолчанию: 6 проверок с интервалом 10 секунд.



```bash

./script.sh

```



Укажите интервал между проверками и их количество:



```bash

./script.sh 5 3

```



В этом примере скрипт выполнит 3 проверки с интервалом 5 секунд.



Чтобы сохранить результаты в другой файл, укажите переменную `LOG\_FILE`:



```bash

LOG\_FILE=custom.log ./script.sh 2 4

```



В этом примере результаты будут записаны в файл `custom.log`. Скрипт выполнит 4 проверки с интервалом 2 секунды.



\## Результаты работы



Результаты мониторинга выводятся в терминал и по умолчанию сохраняются в файл `monitor.log`.



Каждая проверка содержит:



\- Дату и время измерения

\- Время работы системы и среднюю нагрузку

\- Информацию об использовании оперативной памяти

\- Информацию об использовании дискового пространства



\## Обработка ошибок



Скрипт проверяет корректность интервала между проверками и их количества. Оба значения должны быть положительными целыми числами.



Примеры некорректных команд:



```bash

./script.sh 0 3

./script.sh 5 abc

```



В первом примере интервал равен нулю, а во втором вместо количества проверок указано нечисловое значение. В обоих случаях скрипт завершится с сообщением об ошибке.

## Результаты тестирования

Скрипт был протестирован на Ubuntu 22.04, запущенной в виртуальной машине.

Использованная команда:

```bash
./script.sh 2 2
```

В ходе тестирования скрипт успешно выполнил две проверки с интервалом в две секунды. Результаты включали дату и время проверки, время работы системы, среднюю нагрузку, использование оперативной памяти и дискового пространства.

Пример полученного вывода сохранён в файле `sample_output.txt`.

## Ограничения

- Скрипт предназначен для Linux-систем со стандартными командными утилитами.
- Выполняет заданное количество проверок, после чего завершает работу.
- Не отправляет уведомления при превышении допустимого уровня использования системных ресурсов.
